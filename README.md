# Packet Sniffing and Spoofing

This sandbox definition is specifically meant for the SEED Project's packet sniffing and spoofing network security lab: https://seedsecuritylabs.org/Labs_20.04/Networking/Sniffing_Spoofing/

While the hosts used in this lab are technically compatible with the Dockerfiles used in all SEED labs, it is not recommended to use a sandbox defined for a specific lab (such as this) for other labs. Instead, you should use the Ubuntu 20.04 SEED definition, which is generalized for all SEED labs.

If a new sandbox definition is required, you can either contact a cyber range platform administrator or create one yourself: https://docs.platform.cyberrange.cz/user-guide-advanced/sandboxes/sandboxes-overview/
